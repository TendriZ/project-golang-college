# Dokumentasi Kontrak API - Tugas Mandiri Students

Tabel berikut memuat rincian kontrak endpoint REST API untuk entitas `Students`.

| Metode | Endpoint | Parameter | Contoh Body Permintaan | Status yang Mungkin | Contoh Respons |
|---|---|---|---|---|---|
| **GET** | `/api/v1/students` | **Query:**<br>`page` (int, default: 1)<br>`limit` (int, maks: 100)<br>`search` (string)<br>`sort` (id, name, nim, grade)<br>`order` (asc, desc)<br>`is_active` (bool)<br>`min_grade` (float)<br>`max_grade` (float) | *(Tidak ada)* | **200** (OK) | **200:** `{"success": true, "message": "daftar mahasiswa berhasil diambil", "data": [{"id": 1, "nim": 220001, "name": "Sari Dewi Putri", "grade": 95, "is_active": true}], "meta": {"page": 1, "limit": 10, "total": 1, "total_pages": 1}}` |
| **GET** | `/api/v1/students/:id` | **Path:**<br>`id` (int, positif) | *(Tidak ada)* | **200** (OK)<br>**400** (Bad Request)<br>**404** (Not Found) | **200:** `{"success": true, "message": "mahasiswa ditemukan", "data": {"id": 1, "nim": 220001, "name": "Sari Dewi Putri", "grade": 95, "is_active": true}}`<br><br>**404:** `{"success": false, "message": "mahasiswa tidak ditemukan"}` |
| **POST** | `/api/v1/students` | *(Tidak ada)* | `{"nim": 220099, "name": "Mahasiswa Baru", "grade": 85.5}` | **201** (Created)<br>**400** (Bad Request)<br>**409** (Conflict)<br>**415** (Unsupported Media Type)<br>**422** (Unprocessable Entity) | **201:** `{"success": true, "message": "mahasiswa berhasil dibuat", "data": {"id": 8, "nim": 220099, "name": "Mahasiswa Baru", "grade": 85.5, "is_active": true}}` *(Disertai header Location)* |
| **PUT** | `/api/v1/students/:id` | **Path:**<br>`id` (int, positif) | `{"name": "Budi Santoso", "nim": 220002, "grade": 80, "is_active": true}` | **200** (OK)<br>**400** (Bad Request)<br>**404** (Not Found)<br>**409** (Conflict)<br>**415** (Unsupported Media Type)<br>**422** (Unprocessable Entity) | **200:** `{"success": true, "message": "mahasiswa berhasil diganti seluruhnya", "data": {"id": 2, "nim": 220002, "name": "Budi Santoso", "grade": 80, "is_active": true}}` |
| **PATCH** | `/api/v1/students/:id` | **Path:**<br>`id` (int, positif) | `{"is_active": false}` | **200** (OK)<br>**400** (Bad Request)<br>**404** (Not Found)<br>**409** (Conflict)<br>**415** (Unsupported Media Type)<br>**422** (Unprocessable Entity) | **200:** `{"success": true, "message": "mahasiswa berhasil diperbarui sebagian", "data": {"id": 1, "nim": 220001, "name": "Sari Dewi Putri", "grade": 95, "is_active": false}}` |
| **DELETE** | `/api/v1/students/:id` | **Path:**<br>`id` (int, positif) | *(Tidak ada)* | **204** (No Content)<br>**400** (Bad Request)<br>**404** (Not Found) | **204:** *(Tanpa body respons)*<br><br>**404:** `{"success": false, "message": "mahasiswa tidak ditemukan"}` |
